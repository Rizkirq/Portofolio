Tentang saya

Saya lulusan S1 Teknik Informatika Universitas Pasundan dengan IPK 3,65. Untuk tugas akhir, saya melakukan black-box vulnerability assessment pada domain institusi dengan metodologi PTES, lalu menilai risikonya memakai CVSS v4.0.

Di luar kuliah, saya mengasah kemampuan lewat bootcamp dan kompetisi, mulai dari analisis malware Android sampai Capture The Flag. Saya juga punya latar belakang di network administration dan sistem analisis, serta terbiasa bekerja dengan banyak pihak, dari berkoordinasi dengan Project Manager saat magang sampai dengan dosen dan sponsor di organisasi kampus.
